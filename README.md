# 🧾 Générateur de Factures

Logiciel de bureau développé en **Python** (Tkinter) qui permet de créer
rapidement des factures et de les exporter au format **PDF**.

## Fonctionnalités

- Saisie du nom du client
- Ajout d'articles (nom, quantité, prix unitaire)
- Calcul automatique du total par article et du total à payer (en DA)
- Modification et suppression d'un article sélectionné
- Génération d'une facture PDF avec logo, date, tableau des articles et total
- Bouton pour effacer tous les champs

## Technologies

- Python 3
- Tkinter
- ReportLab

## Utilisation

1. Entrez le nom du client
2. Ajoutez les articles un par un
3. Cliquez sur **Générer Facture** : le fichier `facture_NomClient.pdf` est créé
